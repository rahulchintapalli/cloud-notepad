☁️ Cloud Notepad
A beautiful, Apple-inspired note-taking application built with React, TypeScript, and Vite.

Cloud Notepad features a stunning glassmorphism design, smooth micro-animations, and a highly personalized onboarding flow that adapts your workspace based on your unique persona and use case.

✨ Features
Personalized Onboarding: A dynamic "First Visit Experience" that asks for your role (Student, Developer, Writer, etc.) and tailors the default workspace folders to your needs.
Persistent Storage: All of your notes, tabs, and preferences are automatically saved locally in your browser so you never lose your progress.
Premium Apple-Inspired UI: Built with a sleek dark-mode aesthetic, utilizing translucent glass effects, Inter typography, and Framer Motion for buttery-smooth transitions.
Dynamic Workspaces: Seamlessly switch between different notes and folders. The app remembers your active tab and the content inside it.
🚀 Tech Stack
Framework: React 18
Language: TypeScript
Bundler: Vite
Animations: Framer Motion
Icons: Lucide React
Styling: Vanilla CSS (CSS Variables & Glassmorphism)
🛠️ Getting Started
Prerequisites
Make sure you have Node.js installed on your machine.

Installation
Clone the repository:
git clone https://github.com/yourusername/cloud-notepad.git
Navigate to the project directory:
cd cloud-notepad
Install the dependencies:
npm install
Start the development server:
npm run dev
Open your browser and visit http://localhost:5173 to see the app in action!
🖌️ Design System
The application relies heavily on a custom vanilla CSS design system located in src/index.css. It features:

Core color tokens for backgrounds, text, and accents.
Reusable .glass and .card utility classes for effortless UI consistency.
Smooth cubic-bezier transitions for hover and layout effects.
